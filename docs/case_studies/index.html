在 1,000 个虚拟居民的统计里,我们看到 22.7% 的居民被推送带去了新地方。 但这三位是具体的人 — 用她们 / 他的 14 天真实路径,讲清楚"推送如何改变一个人"。

Mary(75 岁退休)、Mike(26 岁工程师)、Frank(64 岁建筑工)是这 1,000 名虚拟居民中的 3 位。 我们从 seed_43_positions.json(每 5 分钟一次位置记录,共 14 天)+ snapshot.json(523MB 的仿真完整状态:agent 收到的真实推送内容 / agent 的真实 plan + reason / agent 遇到的真实邻居 profiles)中复原了他们每日的真实行程、决策瞬间、推送内容、对话对象。 每页都包含真实的 personality 雷达图 + POI 每日访客时序图。 叙事文字基于真实数据骨架 + 简单第一人称润色,试图把"22.7% 响应率"这个抽象数字翻译成具体故事。

这些案例是怎么构建的?

每位 agent 的 14 天行程都来自真实模拟数据 — seed_43_positions.json 每 5 分钟记录一次该 agent 的所在 location_id。我们把 location_id 翻译成 Lane Cove 的真实建筑或街道 (来自 OpenStreetMap 数据),识别出每个"停留 ≥ 20 分钟"的地点,以及"推送下她去了但基线下她从没去过"的新地点。

叙事文本 (例如 "她和 Anne 一起约去 Longueville Park" 这种细节) 是基于数据骨架的合理虚构 — Anne 这个角色是真实存在的另一位 HP 响应者邻居 (从 spillover 数据反推),但她们具体说了什么话不在数据里。
